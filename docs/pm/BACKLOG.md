### Permanently Out of Scope (per /staff ruling)

- **`ticky verify-snippet` subcommand** to generate AWS CLI boilerplate. Reason: AWS deprecates flags every ~18 months; ticky should not own AWS API tracking. Revisit only if cross-account ticket volume exceeds 20/month (current rate is ~3-5/month based on CallHero audit).
- **YAML verification schema rendered into HTML.** Same reason as above.
- **Commit-SHA-against-main validation.** Would require git as a dep + detached-HEAD handling. Out of scope for a thin urllib-based ticket tool.
- **Sub-templates per class** (separate `cross-account-grant.md` template file). One template with class-driven prompt branching is sufficient. Avoids fragmenting authority.
- **AWS Support workflow integration / ADO-level two-signature enforcement.** Belongs in the requesting project's process docs (e.g., CallHero), not in ticky.
- **Retroactively re-tagging historical ADO tickets.** Manual ops; not a ticky feature.
